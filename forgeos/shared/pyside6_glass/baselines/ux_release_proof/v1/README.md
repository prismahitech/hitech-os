# UX Release Proof Baselines (v1)

Authoritative baseline ownership:

- Semantic baseline: `semantic_baseline.json` (primary release authority)
- Visual baseline manifest: `visual_baseline_manifest.json` (secondary reference only)

Rules:

1. Baselines are refreshed only with explicit operator action.
2. Default proof runs never auto-refresh baseline files.
3. Semantic comparison is release-critical; screenshots are supporting evidence.
4. Baseline updates must be reviewed together with capability delta and comparator report.
