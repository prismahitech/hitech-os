# Catálogo de ingredientes

Ingredientes iniciales disponibles:

- `hero_header`
- `kpi_strip`
- `chart_panel`
- `table_panel`
- `filter_bar`
- `search_bar`
- `actions_panel`
- `status_bar`
- `empty_state`
- `error_state`
- `detail_form`
- `tabs_section`
- `activity_feed`
- `inspector_panel`
- `summary_cards`
- `stale_data_banner`

Cada ingrediente define:

- `id`
- `label`
- `suggested_zone`
- `description`
- `requires_data`
- `stability`

El catálogo describe piezas de contenido. No define estilo final ni autoridad visual.
