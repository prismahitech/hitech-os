# PySide6 Glass Template Console

## Cómo ejecutar:

### Opción 1: Archivo .bat (Recomendado)
- **Run_Console.bat** - Doble clic para abrir la aplicación

### Opción 2: Desde línea de comandos
```cmd
cd "F:\repos\hitech-os\forgeos\shared\pyside6_glass\templates\1.original"
py -3 starter.py
```

### Opción 3: Archivo .py (solo si Windows está configurado)
- **starter.py** - Doble clic (requiere configuración de Windows)

## Archivos:
- `starter.py` - Script principal Python
- `Run_Console.bat` - Launcher para Windows
- `visuals/` - Módulos de interfaz gráfica
