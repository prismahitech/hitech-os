# PRISMA Visual Lifecycle Orchestrator

This package is a coordination layer over the existing visual promotion authorities. It must preserve their ownership of discovery, semantic authority, exact binding, authorization, mutation, projection generation, runtime evidence, and certification.

This draft registers the workstream scope so the live Workstream Collision Gate can evaluate the implementation branch. The package remains unimplemented until that gate passes. This coordination file does not authorize a target mutation or claim G-01 closure.
