# Visual Promotion machine contracts

Owned by Chat 6. These contracts formalize the parallel interoperability contract without becoming NDC, Identity, RIFAT, Target Index or product authority.

- candidate.schema.json: candidate-only exchange record and closed vocabularies.
- candidate-shard-manifest.schema.json: surface shard provenance/accounting envelope.
- control-plane.contract.json: authority domains, write ownership, anti-rediscovery reasons, Atlasfin-first, Materiality standby, zero-loss and no-fake-green invariants.

The Control Plane validates and plans. It does not mutate product runtime or canonical registries.
