# PRISMA Marketing Production Master Plan V1

Status: `PLANNING_BASELINE`
Owner: Sharon
Scope: PRISMA OS + 11 registered verticals + PRISMA Change Assurance

## 1. Objective

Create a reusable marketing production system that produces premium, high-impact assets with low incremental effort. The system must preserve PRISMA's visual language while allowing each vertical to have its own business context, imagery, KPIs, UI and message.

## 3. Visual doctrine

### PRISMA OS

- Dark premium enterprise presentation.
- Realistic / photorealistic sector environment as contextual layer.
- Translucent dark glass panels, thin borders, subtle blur and depth.
- Cyan/teal as the primary operational accent.
- Blue for informational/structural states.
- Violet for analytics/secondary emphasis.
- Amber for attention.
- Red for critical states.
- Green for healthy/complete states.
- Clean modern typography, large KPI numbers, restrained copy.
- Linear, minimal iconography.
- Product UI is evidence of the message, not decoration.

### PRISMA Change Assurance

Keep PRISMA's visual DNA, but shift the narrative to technical evidence:

- software architecture;
- repository/diff/graph metaphors;
- Change Studio;
- Authority;
- Verification;
- Evidence;
- PASS / BLOCKED / UNKNOWN.

Avoid generic "cyberpunk hacker" aesthetics. The desired impression is enterprise engineering, governance, traceability and proof.

## 4. Production model

Do not build 11 separate visual identities.

Build one PRISMA visual system + six reusable masters:

1. Hero
2. Dashboard
3. Problem / Insight
4. Product / Solution
5. Carousel
6. One-pager

Each vertical changes only the controlled variables: scene, business problem, KPIs, UI modules, copy and CTA.

## 5. Asset kit per OS vertical

Each vertical receives 8 master assets:

1. Hero principal — awareness / positioning.
2. Dashboard hero — product proof.
3. Problem — pain/identification.
4. Solution — capabilities and benefit.
5. Educational carousel — 5–7 slides.
6. One-pager — sales/prospecting.
7. Short video — 15–20 seconds.
8. Story/status — fast repeatable proof point.

This creates 88 planned OS assets from the same six master templates.

## 6. Vertical-specific treatment

### Tienda de conveniencia
Hero: store aisles, checkout, refrigerators.
UI: sales, catalog, low stock, cash, promotions.
Core message: control every sale and product in one place.

### Restaurante / cafetería
Hero: contemporary restaurant, tables, counter/bar.
UI: tables, orders, sales, occupancy, ticket, kitchen, inventory.
Core message: every table, order and peso under control.

### Farmacia
Hero: modern pharmacy, counter, shelving.
UI: products, lots, expiration, stock, returns, alerts.
Core message: precise control for sensitive operations.
Claim rule: do not imply legal/health certification unless separately evidenced.

### Estética / barbería / salon
Hero: premium salon/stations/reception.
UI: agenda, appointments, clients, services, commissions, packages.
Core message: less organizing, more serving clients.

### Ferretería
Hero: professional hardware store, racks, counter.
UI: catalog, quotes, inventory, sales, stock, clients.
Core message: find, quote, sell and control without losing the thread.

### Ropa / boutique
Hero: contemporary boutique.
UI: variants, sizes, products, sales, stock, clients, promotions.
Core message: collections can change; operational control should not.

### Taller / reparaciones
Hero: professional workshop.
UI: work orders, equipment/vehicles, services, parts, technicians, clients.
Core message: from intake to delivery, keep the job under control.

### Venta en campo / ruta
Hero: salesperson, vehicle, route.
UI: customers, routes, orders, sales, inventory, deliveries.
Core message: sell where the business happens and supervise from anywhere.

### Abarrotes con báscula
Hero: grocery counter + weighing area.
UI: weight, product, price, inventory, sales, cash.
Core message: when price depends on weight, every operation matters.

### Food truck / punto móvil de comida
Hero: urban food truck, evening/night context.
UI: sales, products, orders, inventory, cash, mobility.
Core message: the business moves; the operation moves with it.

### Servicios Profesionales y Corporativos
Hero: premium office, documents, meeting.
UI: customers, cases, services, pending work, documents, compliance, owners, deadlines.
Core message: turn scattered operations into visible, traceable and controlled work.

## 7. PRISMA Change Assurance asset kit

Initial 12 assets:

1. Hero principal.
2. Problem: ungoverned changes.
3. Six-stage map.
4. Evidence chain.
5. PASS / BLOCKED / UNKNOWN.
6. Change Studio.
7. Authority Pack.
8. Verify.
9. Evidence Report.
10. LinkedIn thought-leadership carousel.
11. Demo video.
12. Enterprise one-pager.

Primary narrative:
CHANGE REQUEST → UNDERSTAND → RESOLVE → AUTHORIZE → OBSERVE → VERIFY → PROVE

Core message:
**Know what can change. Control what does. Prove the result.**

Evidence doctrine:
**No evidence. No green.**

Marketing claim boundary:
- Do not claim production certification, enterprise readiness, legal/privacy certification or universal repository compatibility unless a separate evidence gate explicitly supports the claim.
- UNKNOWN must remain a legitimate product outcome; marketing should not imply that uncertainty is automatically a pass.

## 10. Sharon's working rule

Never ask "what design do I create next?"

Ask:

> Which master am I cloning, and which controlled variables am I changing?

The target is production by system, not one-off design.

## 11. Governance alignment

PRISMA's visual architecture defines one editable visual authority with many product/runtime projections. Marketing assets should therefore be treated as governed outputs of the same visual system rather than competing mini-identities. Runtime screens may supply evidence and screenshots, but the visual system itself remains centralized.
