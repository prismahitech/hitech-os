# PRISMA Visual Change Doctrine

Status: `STABLE_INVARIANTS`

This file contains only stable invariants. It intentionally contains no current counts, mutable SHAs, chat states or runtime snapshots.

1. Discovery is not binding.
2. Binding is not authorization.
3. Authorization is not mutation.
4. Mutation is not certification.
5. Candidate is not authority.
6. Promotion readiness is not canonical registration.
7. Canonical registration is not Work Entry authorization.
8. Work Entry authorization is not GVAE APPLY.
9. Source/static PASS is not runtime visual green.
10. Functional PASS is not visual PASS.
11. Visual similarity is not semantic identity.
12. Atlasfin recipe equality is not canonical semantic equivalence.
13. No evidence is not green.
14. Unknown remains unknown until an owning authority resolves it.
15. A derived graph or index is not authority merely because it is generated.
16. A generated artifact is never hand-edited to correct canonical truth.
17. Canonical state and live overlay remain separate.
18. Live coordination state cannot overwrite canonical `main` truth.
19. NDC defines neutral meaning; specific surface IDs define projection/location.
20. UI implementation locates meaning; it does not define canonical meaning.
21. Code Atlas evidence establishes repository facts; impact radius is not authorization.
22. Factory Ledger controls capability maturity and anti-rework.
23. Authority Mesh controls task-exact authorization and protected scope.
24. Atlasfin is cockpit/reference/evidence, not a semantic writer or product writer.
25. A planner, reducer, simulator or recommendation engine may explain allowed next evidence; it may not grant itself mutation authority.
26. Missing, stale, conflicted or unproven authority must fail closed.
27. Scores and percentages are informational only; they never authorize APPLY.
28. Runtime claims require runtime evidence.
29. Product/runtime mutation requires its own exact governed path.
30. When authority is insufficient, represent the gap rather than inventing the answer.

Mnemonic:

> Lo neutral define significado. Lo específico define ubicación.
