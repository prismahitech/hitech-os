# PRISMA Process Phase, Blocker, Cohort and Writer Model

Status: `FOUNDATION_V1_CANONICAL_CONTRACT`

## 1. Phase/head model

The process model distinguishes these identities:

- `phaseBootstrapHead`: canonical main used to start a phase.
- `currentCanonicalMain`: current canonical `main` at observation time.
- `workerBaseHead`: head from which a worker started.
- `workerHead`: worker output head.
- `composerHead`: head containing composed phase output.
- `receiptHead`: head the receipt actually proves.
- `statusBranchHead`: current coordination branch head.
- `ciHead`: commit tested by a CI run.
- `runtimeObservedHead`: source commit tied to runtime proof when known.

These values are not interchangeable.

A phase is stale when its evidence refers to an earlier head and relevant governed sources changed. A later `currentCanonicalMain` alone does not prove relevant drift; the reducer must compare relevant sources.

## 2. Blocker taxonomy rule

The Operating Graph uses a cross-domain blocker **family** while always preserving the original source code.

It never rewrites source meaning to make dashboards prettier.

Initial crosswalk:

| Canonical family | Source domain | Preserved source code |
|---|---|---|
| `SEMANTIC_AUTHORITY_GAP` | visual-promotion | `BLOCKED_MISSING_SEMANTIC_AUTHORITY` |
| `APPLICATION_AUTHORITY_GAP` | visual-promotion | `BLOCKED_MISSING_APPLICATION_AUTHORITY` |
| `BINDING_GAP` | visual-promotion | `BLOCKED_MISSING_BINDING` |
| `PHYSICAL_DRIFT` | visual-promotion | `BLOCKED_PHYSICAL_DRIFT` |
| `LOCATION_CONFLICT` | visual-promotion | `BLOCKED_MULTI_REGION_CONFLICT` |
| `PROJECTION_DEBT` | promotion projection readiness | `CANONICAL_PROJECTION_REQUIRED_MISSING` |
| `PROJECTION_AMBIGUITY` | promotion projection readiness | `AMBIGUOUS` |
| `AUTHORITY_RECONCILIATION_REQUIRED` | promotion projection readiness | `PRODUCT_CANDIDATE_AUTHORITY_RECONCILIATION_REQUIRED` |

Other Target Index, Work Entry, Authority Mesh, Factory Ledger or runtime blocker codes remain source-native until explicitly mapped. An unmapped code becomes `UNCLASSIFIED_SOURCE_BLOCKER` with `requiresTaxonomyUpdate=true`, never a guessed category.

## 3. Surface cohort model

A surface registry and a phase cohort are different things.

The canonical all-surface registry is derived from:

`apps/terminal-de-venta-system/.prisma-ui/surfaces.json`

Promotion Readiness cohort membership is derived from:

`prisma-html/governance/visual-promotion/contracts/control-plane.contract.json#/surfaceKeys`

Protected surfaces for that cohort are derived from:

`#/protectedSurfaces`

Atlasfin is represented as `REFERENCE_ROLE`, not as a product `surfaceKey`.

The Operating Graph stores the derivation source for cohort membership rather than creating a second manually maintained surface list.

## 4. Writer model

| Writer role | Meaning |
|---|---|
| `CANONICAL_WRITER` | owns a domain authority or curated canonical record |
| `GENERATED_WRITER` | regenerates a derived artifact from locked sources |
| `RUNTIME_WRITER` | writes product/runtime state under separate authorization |
| `STATUS_WRITER` | writes coordination-only status |
| `EVIDENCE_WRITER` | writes receipts/evidence without promoting authority |
| `PROTECTED_CONSUMER` | may consume but not write the source |

Examples:

- NDC curation is the semantic canonical writer for NDC meaning.
- Identity registries are visual-meaning/recipe authority.
- RIFAT is exact visual-location/projection authority.
- Target Index is generated by its governed generator, not hand-edited.
- Visual Promotion workers own only their declared candidate/status lanes.
- Operating Graph generated outputs are written only by the future Operating Graph generator.
- Atlasfin is a protected consumer/reference producer for semantic decisions.

## 5. Collision rules

Block when:

1. two canonical writers claim the same artifact/domain;
2. a generated artifact is manually edited;
3. a planner or cockpit attempts canonical mutation;
4. a live status writer attempts to update canonical truth;
5. a worker writes composer-owned or another worker's scope;
6. a graph projection attempts to promote candidate evidence into authority;
7. a stale worker/receipt is treated as current without relevant-drift evaluation.

## 6. State composition rule

For any process object, the reducer should be able to explain separately:

- canonical state;
- live overlay state;
- freshness;
- blocker family;
- preserved source blocker;
- owning authority;
- current writer;
- evidence refs;
- next evidence obligation.

No field named `ready` is sufficient by itself to imply mutation authorization.
