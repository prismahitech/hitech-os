# Architecture Decision Records (ADR)

This folder stores architecture decisions in chronological order.

## Naming

Use this format for ADR files:

- `0001-title.md`
- `0002-title.md`

Rules:

1. Four-digit numeric prefix.
2. Lowercase kebab-case title.
3. One decision per ADR.

## Workflow

1. Copy `0000-template.md`.
2. Fill in context, decision, and consequences.
3. Submit review with impacted teams.
4. Merge after approval.
5. Link superseding ADRs when applicable.
