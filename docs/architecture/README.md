# Architecture Docs Index

Canonical architecture documentation lives in this directory.

## Scope

- System topology and boundaries
- Service interaction and data flow
- Runtime and deployment architecture
- Cross-cutting concerns (security, observability, reliability)

## Rules

- Keep architecture docs shallow and navigable.
- Do not store archives, snapshots, logs, or tool dumps here.
- Use ADRs in `docs/adr/` for binding architecture decisions.
