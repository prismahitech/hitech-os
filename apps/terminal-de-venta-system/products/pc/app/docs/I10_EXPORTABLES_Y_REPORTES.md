# I10 exportables y reportes

Esta capa agrega una superficie de salida para CSV y JSON, más una zona ejecutiva detallada y un tablero de contratos de reporte.

## Entradas de verdad
- snapshot SQLite de PC
- métricas agregadas de inventario, compras, auditoría y outbox
- contratos documentados para productores/consumidores

## Salidas clave
- pack ejecutivo semanal
- pack ejecutivo mensual
- margen por categoría
- excepciones de stock
- SLA de sincronización
