# PRISMA POS packshots 04J

Packshots PNG transparentes 512x512 para la Tablet POS.

Contrato runtime:

```text
products/tablet/app/public/pos-packshots/*.png -> /pos-packshots/*.png
```

Estos assets son ilustraciones genéricas propiedad del paquete, no arte oficial de marcas.
Sirven para que el catálogo se vea premium y consistente mientras se sustituyen por fotografía licenciada cuando el negocio ya tenga proveedor visual formal.

Reglas visuales:
- fondo transparente;
- producto centrado;
- lectura clara en card chica y miniatura de ticket;
- sin cajas blancas, sin checkerboard, sin logos pirateados;
- 512x512 para Next/static y densidad retina.
