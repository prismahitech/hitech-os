# I01 Glosario visible es-MX

## Producto
- Panel administrativo de inventario
- Terminal de venta

## Operación
- Catálogo
- Existencias
- Conteos físicos
- Compras
- Recepción
- Reabasto
- Auditoría
- Sincronización

## KPIs y control
- Ventas netas
- Número de tickets
- Ticket promedio
- Top SKUs
- Quiebres de stock
- Exactitud de inventario
- Merma
- Cancelaciones
- Fill rate

## Palabras que sí se toleran por uso técnico
- SKU
- barcode, cuando sea parte de una incidencia técnica o de validación
- offline
- sync, solo en contexto técnico interno

## Preferencia visible
Privilegiar español claro de operación mexicana. Evitar anglicismos de plantilla en navegación y headings visibles.
