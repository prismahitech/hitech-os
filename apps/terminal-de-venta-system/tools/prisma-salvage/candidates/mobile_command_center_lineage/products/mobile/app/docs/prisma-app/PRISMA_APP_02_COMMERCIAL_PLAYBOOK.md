# PRISMA App 02 - Commercial playbook

## Posicionamiento

PRISMA App es la capa móvil de visibilidad para dueños y supervisores.

No se vende como “app multisucursal”. Se vende como:

```text
Tu negocio al día, desde tu celular.
```

## Mensaje base

Consulta ventas, caja, inventario, alertas y reportes rápidos desde el celular sin estar físicamente en el local.

## Dolor del cliente

El dueño normalmente depende de:

- llamadas
- WhatsApps
- cortes manuales
- fotos de tickets
- capturas de pantalla
- reportes tarde
- encargados que dicen “todo bien” aunque algo huela raro

PRISMA App convierte ese caos en una lectura móvil clara.

## Pitches por tipo de cliente

### Cliente de una tienda

```text
Con PRISMA App puedes ver cómo va tu negocio hoy: venta, caja, productos bajos y alertas importantes desde el celular.
```

### Cliente con empleados

```text
PRISMA App te ayuda a revisar caja, cortes, inventario y alertas sin estar encima del mostrador todo el día.
```

### Cliente multisucursal

```text
Además de la vista general, PRISMA App puede activar MultiSucursal para comparar tiendas, ranking, sync y alertas por sucursal.
```

## Qué no decir

No decir:

- app para cadenas
- app solo para multisucursal
- vigilancia de empleados
- reemplazo de PC
- reemplazo de Tablet

## Qué sí decir

- visibilidad móvil
- reportes rápidos
- alertas útiles
- negocio al día
- MultiSucursal opcional
- datos desde Tablet y PC

## Frases comerciales

```text
No tienes que estar en el local para saber cómo va tu negocio.
```

```text
Tu venta, caja e inventario en una lectura móvil clara.
```

```text
Tablet vende sola, PC administra cuando existe y PRISMA App te mantiene enterado.
```

```text
Si tienes varias tiendas, MultiSucursal te ayuda a saber cuál necesita atención primero.
```

## Objeciones

### “Yo solo tengo una tienda”

Respuesta:

```text
Justo por eso PRISMA App inicia con Hoy, Ventas, Caja, Inventario y Alertas. MultiSucursal está separado para cuando el negocio crezca.
```

### “No quiero revisar otro sistema”

Respuesta:

```text
No es otro backoffice. Es una lectura rápida desde el celular para saber si todo va bien o si algo requiere atención.
```

### “¿Me va a llenar de notificaciones?”

Respuesta:

```text
La idea es alertar solo lo importante: caja, productos críticos, ventas raras, sync y eventos sensibles.
```
