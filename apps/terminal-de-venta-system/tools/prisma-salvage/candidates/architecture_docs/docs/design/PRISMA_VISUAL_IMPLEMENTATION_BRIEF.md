# Prisma Visual Implementation Brief

Regla madre:

Tablet vende sola.
PC gobierna cuando existe.
Shared Kernel es contrato.
Sync es puente.
Eventos son verdad operacional.

Estos documentos describen objetivo de implementacion visual. No afirman que la UI final ya este implementada.


Tablet: top runtime/sync/terminal, main search/product list, right cart/ticket, bottom primary actions. PC: sidebar, header state, KPI dashboard, operational tables, exception panels, detail views. No hardcodear claims como implementados hasta las etapas de codigo.
