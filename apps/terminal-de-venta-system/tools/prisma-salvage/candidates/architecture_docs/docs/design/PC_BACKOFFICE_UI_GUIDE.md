# Pc Backoffice Ui Guide

Regla madre:

Tablet vende sola.
PC gobierna cuando existe.
Shared Kernel es contrato.
Sync es puente.
Eventos son verdad operacional.

Estos documentos describen objetivo de implementacion visual. No afirman que la UI final ya este implementada.


PC debe sentirse como backoffice control tower, no POS gigante: sidebar por modulos, header con branch/terminal/sync, KPI cards, tablas, exception panels y detail views.
