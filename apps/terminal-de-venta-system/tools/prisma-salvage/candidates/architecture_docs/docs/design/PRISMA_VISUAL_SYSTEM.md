# Prisma Visual System

Regla madre:

Tablet vende sola.
PC gobierna cuando existe.
Shared Kernel es contrato.
Sync es puente.
Eventos son verdad operacional.

Estos documentos describen objetivo de implementacion visual. No afirman que la UI final ya este implementada.


Tablet es caja/POS tactil. PC es torre de control/backoffice. Shared components: `StatusBadge`, `KpiCard`, `DataTable`, `EmptyState`, `ErrorState`, `SyncStatus`, `PermissionGate`, `ConfirmDialog`, `ExportButton`, `OperationalAlert`.
