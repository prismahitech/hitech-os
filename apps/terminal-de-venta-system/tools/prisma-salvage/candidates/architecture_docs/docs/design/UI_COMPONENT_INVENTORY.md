# Ui Component Inventory

Regla madre:

Tablet vende sola.
PC gobierna cuando existe.
Shared Kernel es contrato.
Sync es puente.
Eventos son verdad operacional.

Estos documentos describen objetivo de implementacion visual. No afirman que la UI final ya este implementada.


Tablet-only: `TouchProductSearch`, `TouchCart`, `TouchNumpad`, `CheckoutButton`, `TicketSummary`, `OfflineBanner`, `OutboxMiniPanel`. PC: `BackofficeSidebar`, `ExecutiveDashboard`, `InventoryExceptionTable`, `AuditTimeline`, `SyncConflictTable`, `PurchaseOrderTable`, `ReceivingPanel`, `ReplenishmentSignals`. Shared: `StatusBadge`, `KpiCard`, `DataTable`, `EmptyState`, `ErrorState`, `SyncStatus`, `PermissionGate`, `ConfirmDialog`, `ExportButton`, `OperationalAlert`.
