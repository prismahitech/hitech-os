# PRISMA Verticales 00E - Límites Tablet / PC


## Tienda de conveniencia

### Tablet debe hacer
- Ejecutar el flujo diario: venta de productos por código de barras, ticket rápido, efectivo, tarjeta, devolución simple y corte de turno.
- Mostrar estados operativos y corrección rápida.
- Permitir continuidad offline si la política del giro lo permite.
- Registrar eventos sensibles sin pedirle al usuario que entienda sincronización técnica.

### PC debe hacer
- Administrar configuración avanzada.
- Gobernar catálogo, permisos, auditoría y reportes profundos.
- Resolver conflictos y consolidar información.
- Preparar datos maestros para Tablet.

### Bloqueos explícitos para Tablet
- proveedores completos en Tablet.
- compras formales en Tablet.
- conteo físico profundo en caja.

### Regla de escape
Si un cajero necesita salir de la venta para entender el negocio, el diseño está sobrecargando Tablet. Si un administrador intenta operar configuración desde la Tablet en hora pico, el producto está invitando al desastre con moño.
