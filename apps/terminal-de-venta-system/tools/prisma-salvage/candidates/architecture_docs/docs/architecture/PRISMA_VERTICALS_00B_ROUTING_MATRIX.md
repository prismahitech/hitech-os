# PRISMA Verticales 00B - Matriz de ruteo Tablet/PC

La ruta visible se decide por vertical, capacidad, permiso y superficie. No por antojo ni por boton sobrante.

## Nucleo comun Tablet

| Ruta | Proposito |
|---|---|
| Vender | iniciar venta |
| Cobro | cerrar ticket |
| Ventas de hoy | consultar tickets del dia |
| Turno | abrir/cerrar caja |
| Devoluciones | registrar devolucion |
| Existencias | consultar stock operativo |
| Pendientes por enviar | explicar sync sin jerga tecnica |
| Exportar | sacar datos locales con permiso |
