## Vertical convenience

- Pregunta: esta necesidad de convenience pertenece al core comun o a una extension vertical aislada?

- Evidencia requerida: capacidad declarada, permiso sensible, evento auditable, estado offline y smoke check.
- Rechazo automatico: si obliga a Tablet a funcionar como backoffice pesado o si bloquea una venta simple sin motivo operativo.
