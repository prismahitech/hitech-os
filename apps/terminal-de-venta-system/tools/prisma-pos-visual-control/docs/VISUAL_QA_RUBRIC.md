# VISUAL_QA_RUBRIC

Checks visuales obligatorios para `/pos`:

- COBRAR manda.
- Ticket se lee.
- Cards no se lavan.
- Producto tiene pedestal.
- Fondo no compite.
- Texto secundario se lee.
- Blur no empasta.
- Glass tiene borde/highlight.
- Total se distingue.
- Sidebar/header no roban foco.
- Estados hover/active visibles.
- Reduced motion considerado.

Resultado esperado: si una persona normal no nota mejora visual, el paquete no cuenta. Sí, la vara está bajita y aun así hay CSS que se tropieza.
