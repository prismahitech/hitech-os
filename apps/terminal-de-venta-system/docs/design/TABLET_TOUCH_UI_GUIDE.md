# Tablet Touch Ui Guide

Regla madre:

Tablet vende sola.
PC gobierna cuando existe.
Shared Kernel es contrato.
Sync es puente.
Eventos son verdad operacional.

Estos documentos describen objetivo de implementacion visual. No afirman que la UI final ya este implementada.


Tablet debe sentirse como POS/caja real: boton cobrar grande, ticket visible, busqueda rapida, barcode/SKU primero, total grande, errores no tecnicos, offline/sync visible, low stock y confirmacion de ticket cerrado. Screens: `/pos`, `/catalog`, `/sales/today`, `/inventory/low-stock`, `/events/outbox`, `/settings/export`.
