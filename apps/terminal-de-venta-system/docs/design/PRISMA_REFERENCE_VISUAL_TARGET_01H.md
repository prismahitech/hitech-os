# PRISMA Reference Visual Target 01H

## Objetivo

Alinear PRISMA App, Tablet y PC a la referencia visual aprobada sin mover layout.

Esta ronda no rediseña pantallas. Solo prepara la base para piel visual y efectos:

- dark glass cinematografico
- fondo azul-negro profundo
- brillo dorado calido
- bordes luminosos finos
- productos en vitrina iluminada
- carrito o panel derecho dominante
- estados hover/focus premium
- textura atmosferica sin ruido excesivo

## Regla madre

No mover layout.

Permitido:

- color
- sombras
- blur
- glassmorphism
- bordes
- brillos
- reflejos
- estados hover/focus
- pedestal visual de productos
- pulido de CTA

Prohibido:

- cambiar rutas
- cambiar estructura TSX
- cambiar grid o columnas
- mover sidebar, carrito, topbar o cards
- reemplazar componentes funcionales
- meter datos fake para tapar funcionalidad

## Direccion estetica

Direccion principal: lujo editorial oscuro.

Soporte: tecnico calido.

Traduccion practica: que se sienta como terminal retail premium, no como dashboard generico con modo oscuro puesto a las carreras.

## Criterio de aceptacion visual

PASS si:

- se reconoce la familia PRISMA en las tres superficies
- el dorado manda sin parecer feria de pueblo
- las cards tienen profundidad
- los productos se sienten exhibidos
- el CTA principal domina
- PC conserva cara de backoffice
- Tablet conserva cara de POS
- Mobile conserva cara de app de supervision

FAIL si:

- parece dashboard SaaS comun
- el dark se ve plano
- el dorado parece boton de casino barato
- se movio layout
- se tocaron rutas o composicion
- las capturas no comparan contra la referencia
