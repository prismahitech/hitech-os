# Responsive Breakpoints

Regla madre:

Tablet vende sola.
PC gobierna cuando existe.
Shared Kernel es contrato.
Sync es puente.
Eventos son verdad operacional.

Estos documentos describen objetivo de implementacion visual. No afirman que la UI final ya este implementada.


Tablet: touch targets legibles, ticket/cart visible o a un toque, boton cobrar dominante, estado offline/sync arriba. PC: sidebar estable, tablas densas, detail views y header operativo.
