# PRISMA Visual OS - POS Touch Binding 00B

## Frase madre

Tablet POS debe sentirse premium, pero operar como caja rápida. Si una decisión visual reduce velocidad, legibilidad o confianza del cobro, pierde contra operación.

## Qué activa este paquete

00B convierte `/pos` en la primera pantalla conectada al PRISMA Visual Operating System. No es una reinterpretación del layout. Es un binding controlado que permite que las perillas futuras trabajen sobre una superficie real.

## Perillas aplicadas en esta iteración

| Perilla | Valor operativo | Impacto |
|---|---:|---|
| Tono visual | POS Touch | Balancea premium y claridad |
| Densidad | Media-amplia | Mantiene targets táctiles |
| Profundidad | Glass controlado | Da marca sin tapar contenido |
| Contraste | Balanceado alto | Mejora lectura de cobro/producto |
| Énfasis funcional | Carrito + COBRAR | La venta manda sobre decoración |
| Movimiento | Corto, reducible | Respeta operación rápida |

## Reglas

- El fondo acompaña, no compite.
- El carrito no se esconde.
- COBRAR domina sólo cuando hay ticket activo.
- Producto, precio y stock siguen legibles.
- La capa visual debe estar acotada por data attributes.
