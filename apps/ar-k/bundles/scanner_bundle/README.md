# Ar-k Scanner Bundle

Governed handoff bundle for `stage_01_scan`.

The installer is self-contained after unzip, requires explicit `--root`, installs the full homologated bundle surface into `<root>/bundles/scanner_bundle`, stores installer state in `<root>/.ark_install/scanner_bundle/`, and keeps Scanner observed-only.

Verify-mode example JSON artifacts are generated only under `<root>/.ark_install/scanner_bundle/verification_outputs/<timestamp>/`.
