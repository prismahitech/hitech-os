# Synapse-X GUI

## Cómo ejecutar:

### Opción 1: Archivo .bat (Recomendado)
- **Run_GUI.bat** - Doble clic para abrir la aplicación

### Opción 2: Desde línea de comandos
```cmd
cd "F:\repos\hitech-os\apps\synapse-x"
py -3 synapse-x_starter.py --root "F:\repos\hitech-os\apps\synapse-x"
```

### Opción 3: Archivo .py (solo si Windows está configurado)
- **synapse-x_starter.py** - Doble clic (requiere configuración de Windows)

## Archivos:
- `synapse-x_starter.py` - Script principal Python
- `Run_GUI.bat` - Launcher para Windows
- `src/` - Código fuente de la aplicación
- `.synapse_hidden/` - Configuraciones internas
